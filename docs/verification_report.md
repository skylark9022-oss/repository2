## 합성 자료가 포함한 "지저분한" 표기

좌표: 십진수, `35 30.123 N`, `35-30.123S`. 날짜: 연/월/일 분리(월·일 결측 포함), `YYYY/MM/DD` 문자열, 엑셀 datetime, 날짜 열이 비고 연/월/일만 있는 행. 값: `<0.3`, `1.2±0.3`, 별도 오차 열, 오차 결측. 핵종 라벨: `Cs-137`, `137Cs`, `cs137`, `239,240Pu`, `239+240Pu`, `240Pu/239Pu`. 단위: 헤더 괄호 `(Bq/m3)`, `(mBq/m3)`, `(atom ratio)` 또는 단위 열.

## 검증이 찾아낸 결함 (수정 완료)

| 결함 | 증상 | 원인 | 수정 |
|---|---|---|---|
| 불확도 열 유실 | wide CSV 에서 Pu-239+240 불확도 485건이 NaN | 오차 열 이름 `Pu239 err` 가 단일 핵종 Pu-239 로 인식되어 값 열 `239,240Pu` 와 짝을 못 찾음 | 이름의 핵종과 맞는 값 열이 없으면 직전 값 열에 연결 |
| 레코드 누락 | long XLSX 에서 654건이 필수값 결측으로 제외 | 날짜 열이 있으면 연/월/일 열을 보지 않아, 날짜 열이 빈 행이 NaT | 날짜 열이 빈 행은 연/월/일 열로 보충 |
| 시각 정보 손실 (잠재) | MARIS `time` 의 시각이 CSV 저장 시 사라짐 | 스키마가 일 단위 | 채취일은 일 단위로 정규화하고 시각은 `notes` 의 `time_utc=` 로 보존 |
| ND 행 제외 (앞서 수정) | "ND" 만 보고된 측정이 값 결측으로 버려짐 | 필수값 규칙 | `below_dl=True` 면 값 결측 허용 |

## 한계 (중요)

- **실제 HAMGlobal2021 파일로는 검증하지 못했습니다.** 합성 자료는 "이런 표기라면 정확히 들어온다"는 것만 보여 줍니다. 실제 파일의 표기가 위 목록 밖이면 `--inspect` 로 확인하고 매핑을 고쳐야 합니다.
- **MARIS 는 실제 형식 파일 9행**(발트해)으로만 대조했습니다. 태평양 자료, 검출한계 미만 행, `dlv`·`area` 변수가 있는 파일은 합성 파일로만 검증했습니다.
- 대조 코드가 파서와 같은 사람이 작성했으므로 같은 오해를 공유할 수 있습니다. MARIS 코드 해석은 파일 enum 과 `dbo_*.csv` 를 각각 독립적으로 썼고, 표 형식은 정답을 먼저 만들고 렌더링했으므로 그 위험은 줄였습니다.

## 실제 자료를 받은 뒤 할 일

1. 변환 후 `python -m pacific_radio.verify maris <nc> <csv>` 또는 `verify tabular … --map …` 실행, 종료 코드 0 확인.
2. `manual_review` 목록(문자 셀)을 눈으로 확인.
3. 원본 발췌본(수십 행)을 `tests/data/` 에 넣고 `tests/test_verification.py` 에 실제 파일 대조를 추가.
