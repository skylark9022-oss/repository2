# 방침 결정 기록 (Decision Log)

결정할 때마다 날짜, 결정 내용, 이유, 영향 범위를 적습니다. 번복하면 지우지 말고 새 항목으로 추가합니다.

## 형식

```
## YYYY-MM-DD  제목
- 결정:
- 이유:
- 영향: (어느 컬럼 / 어느 코드)
- 근거 자료:
```
